# Guido van Rossum

Guido van Rossum je nizozemský programátor a tvůrce programovacího jazyka Python. Narodil se 31. ledna 1956. Python je jednoduchý a přehledný programovací jazyk, který se používá například pro tvorbu aplikací, webů a umělé inteligence.

## Zajímavosti

- Vytvořil programovací jazyk Python.
- První verze Pythonu vyšla v roce 1991.
- Pracoval ve společnostech Google a Microsoft.
- Python pojmenoval podle komediálního seriálu Monty Python.
