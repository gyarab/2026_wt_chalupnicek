# Tim Sweeney

**Tim Sweeney** (*1970*) je americký programátor a podnikatel, který se proslavil především v oblasti počítačových her. Už od mládí se zajímal o počítače a programování. V roce **1991 založil společnost Epic Games**, která se z malé firmy postupně rozrostla v jednoho z významných producentů videoher a herních technologií.

Velkým úspěchem společnosti se stala herní série **Unreal** a především **Unreal Engine**. Jedná se o herní engine, který umožňuje vývojářům vytvářet hry a další 3D aplikace. Unreal Engine dnes používají vývojáři po celém světě a stal se jedním z nejznámějších nástrojů pro tvorbu moderních počítačových her.

Epic Games stojí také za známou hrou **Fortnite** a digitálním obchodem **Epic Games Store**. Sweeney je známý také svými názory na fungování digitálních platforem a dlouhodobě prosazuje větší otevřenost pro vývojáře. Díky své práci patří mezi známé osobnosti současného herního průmyslu.
